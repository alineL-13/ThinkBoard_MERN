# MERN ThinkBoard

> 🚧 **Work in Progress** — This project is currently under development.

A **To-Do List** application built with the MERN stack, created with the goal of learning and practicing the use of **MongoDB as the main database**.

## About the project

This project is being developed as part of my journey in learning full-stack web development.

The idea is to build a task management application using:

- **MongoDB** for data storage
- **Express.js** for building the API
- **React** for the interface
- **Node.js** for the backend
